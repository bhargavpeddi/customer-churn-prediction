# Data source

`telco_customer_churn.csv` is the IBM Telco Customer Churn sample dataset (7,043 customers, 21 columns),
from IBM's public repository [IBM/telco-customer-churn-on-icp4d](https://github.com/IBM/telco-customer-churn-on-icp4d)
(Apache License 2.0). It is included unchanged so the project runs offline.

Each row is one customer: demographics, account details (tenure, contract, billing, charges),
subscribed services, and `Churn` (whether the customer left in the last month).
